# SFINKSAS

Prabangi, interaktyvi profesionalios plaukų priežiūros parduotuvės demonstracinė svetainė. Joje yra mobilioji ir kompiuterio peržiūros, produktų karuselės, paieška, produktų kortelės ir krepšelis.

## Veikianti svetainė

[Atidaryti SFINKSAS per GitHub Pages](https://albertborkovski-cmd.github.io/sfinksas-web/)

## Paleidimas

Reikalinga „Node.js“ 22.13 arba naujesnė versija.

```bash
npm install
npm run dev
```

Atidarykite `http://localhost:3000`.

## Patikra

```bash
npm run lint
npm run build
```

Produktų vaizdai pateikiami optimizuotais „WebP“ failais. Greitos peržiūros užkraunamos pirmiausia, o aukštos raiškos vaizdai – tik naršyklei atsilaisvinus.

Paruoštas statinis leidimas saugomas `docs` aplanke. „GitHub Pages“ jį pateikia tiesiogiai per viešą `github.io` nuorodą.
